# Orientaciones para aportar datos al Observatorio

Esta sección reúne los recursos necesarios para que las organizaciones socias preparen y aporten conjuntos de datos al Observatorio Aguas Amazónicas. Aquí encontrarás la guía con las orientaciones del proceso, las plantillas requeridas para documentar la información y el espacio para enviar los archivos que serán revisados antes de su incorporación a la infraestructura de datos.
